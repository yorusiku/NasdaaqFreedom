# morning-brief

미국장 마감 3시간 뒤, 관심 종목만 정리해서 보내는 개인용 브리핑 시스템.

미국 증시는 한국 시각 새벽 5시(서머타임 기준)에 마감한다. 아침 8시 브리핑은 어제 일이 아니라 **세 시간 전에 끝난 장**을 다룬다. 마감 변동폭과 그 원인, 섹터 대비 위치, 다가오는 실적·공시 일정을 하나로 묶어 카카오톡과 메일로 보낸다.

## 설계도

**→ [시스템 설계도 v2](https://github.com/yorusiku/NasdaaqFreedom/)**

전체 설계가 이 문서 한 장에 들어 있다. 데이터 출처 선택 근거, 아키텍처, 기능별 판정 로직, 화면, 비용, 구현 순서, 리스크. 구현하다 "왜 이렇게 했더라"가 생기면 여기부터 본다.

로컬에서는 `docs/index.html`을 브라우저로 열면 된다.

## 무엇을 하나

| # | 기능 | 내용 |
|---|---|---|
| 1 | 당일 변동폭 | 종가·등락률에 더해 20일 변동성 대비 σ배수, 거래량 배수 |
| 2 | 변동 원인 추정 | 매크로 → 섹터 → 개별 순으로 규칙 판정, 남은 것만 LLM |
| 3 | 섹터 대비 변동 | 종목 등락률 − 섹터 ETF 등락률 = 초과수익 α |
| 4 | 이벤트 D-7 알림 | 실적일·정기보고서 기한·주총·배당·매크로 일정 |

하지 않는 것: 주문, 실시간 시세, 매수/매도 의견, 타인 발송.

## 데이터 출처

| 소스 | 용도 | 키 | 비고 |
|---|---|---|---|
| Polygon | 시세·거래량·섹터 ETF | 필요 | grouped daily bars — 하루 1콜로 전체 |
| SEC EDGAR | 8-K·10-K/Q·DEF 14A | 불필요 | User-Agent 헤더 필수, 초당 10요청 |
| FRED | 매크로 릴리스 일정 | 필요 | CPI·PPI·고용·FOMC |
| Finnhub | 실적 캘린더·뉴스 | 필요 | 유일하게 유료화 위험이 있는 지점 |
| Anthropic | 원인 요약 | 필요 | 규칙 필터 통과분만 호출 |

**비공식 엔드포인트는 쓰지 않는다.** 로빈후드·Investing.com은 공개 주식 API가 없고, 리버스 엔지니어링한 래퍼는 약관 위반에 계정 정지 위험까지 따른다. 같은 데이터를 정식 경로로 받을 수 있으므로 실익도 없다.

## 스택

TypeScript / Node 22 · zod(스키마) · Temporal 또는 date-fns-tz(시간대) · DynamoDB · AWS Lambda

허용 IP 등록을 요구하는 소스가 없어서 VPC와 NAT Gateway가 필요 없다. 전부 서버리스, 월 비용 수천 원.

## 구조

```
morning-brief/
├── docs/index.html        설계도 (GitHub Pages 진입점)
├── src/
│   ├── config.ts          관심종목 · 섹터 매핑
│   ├── clients/           polygon · sec · fred · finnhub
│   ├── collect/           수집
│   ├── analyze/           규칙 판정 → LLM
│   ├── render/            HTML · 텍스트
│   ├── deliver/           ses · kakao
│   └── store/             DynamoDB
├── scripts/
│   ├── run-daily.ts       배치 진입점
│   └── check-sent.ts      08:10 발송 감시
└── tests/
```

## 시작하기

```bash
npm install
cp .env.example .env     # 키 채우기. .env는 커밋되지 않는다
npm run dev              # 로컬 1회 실행
```

## 주의

- **cron은 화~토다.** 미국 금요일장은 토요일 새벽에 끝나므로 월~금으로 두면 금요일장이 브리핑에 실리지 않는다.
- **서머타임.** 3월·11월에 미국 마감 시각이 1시간 이동한다. 오프셋을 직접 계산하지 말 것.
- **API 키는 커밋 금지.** 로컬은 `.env`, 운영은 Secrets Manager.
- 본인 1인이 읽는 용도다. 배포하면 각 제공자의 재배포 약관이 걸린다.
